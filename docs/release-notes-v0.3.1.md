# v0.3.1 — 修复「好友收不到消息」+ 协议模式兜底 + 联想自启动跳转

## 🐞 重点修复:好友整天收不到消息(回归缺陷)

真机日志(09-27 ~ 09-29)显示,多个好友连续多天一条消息都发不出去,日志长这样:

`@text
⚠️ 聊天页顶部显示的是「00:02」而不是「神の名」,放弃该会话
打不开会话: 神の名
`@

**根因**:v0.2.2 加入的「防发错人」校验去**屏幕顶部 15%** 找昵称,而这块区域里经常是**聊天记录的内容** ——
时间戳「00:02」「周日 12:36」、上一条消息「快去上学！」「晚安」。于是被误判为「进错了会话」而主动放弃发送。

**修复**:排除位于**可滚动容器(消息列表)**内的文本(消息行都在列表里,标题栏不在),
再排除时间/日期样式文本;仍然读不到昵称时按原策略继续发送。

## 🛡 协议模式失败自动兜底

协议模式返回「未登录 / 超时 / 异常 / 初始化失败 / 页面异常」时,只要无障碍服务开着,
就自动用无障碍模式再跑一轮(09-27 06:00 就是网页打不开,导致当天完全没发)。

## 🔗 联想等机型的自启动跳转

- 补上**联想**组件 `com.lenovo.security/.purebackground.PureBackgroundActivity`
  (出处:HelloDaemon / XPush / SmsForwarder / DaemonLibrary 等开源实现)与 ZUI 安全中心主页;
- 补齐**荣耀(hihonor)**、**中兴/努比亚(zte.heartyservice)**、**TCL**、**OPPO/realme(oplus.battery)**;
- 每个候选先用 `resolveActivity` 探测,不存在直接跳过;顺序为 厂商自启动管理页 → 安全中心主页 → 应用详情页;
- 全部落空时引导页直接给出**该机型手动路径**。
