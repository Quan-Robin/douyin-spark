# v0.3.0 — 首次使用引导 + 界面美化 + 体积优化

## 🆕 首次使用引导(按手机厂商开权限)

首次启动自动进入引导页:**先选发送方式(无障碍 / 协议)→ 再按机型逐项开权限**。
每一项都实时显示状态,点一下直接跳到对应设置页;国产 ROM 的「自启动 / 后台弹出 / 电池优化」
按厂商走不同跳转链(小米/红米、华为/荣耀、OPPO/realme/一加、vivo/iQOO、三星、魅族、华硕、乐视…),
跳不过去会自动退回系统应用详情页,不会"点了没反应"。

覆盖:无障碍服务 · 悬浮窗 · 关闭电池优化 · 自启动/后台运行 · 通知(13+) · 闹钟和提醒(12+) · 修改系统设置(可选)。
自启动状态系统不提供查询接口,点完设置后勾一下「我已在系统里设置好了」即可记入完成。

## 🎨 界面

- 导航栏 emoji → 矢量图标,选中态高亮;
- 首页重排:状态徽章(模式/无障碍/悬浮窗)+ 下次运行 + 今日发送 + 快捷操作 + 模式卡片 + 帮助入口;
- 卡片与按钮统一圆角描边与涟漪反馈,配色/间距统一。
