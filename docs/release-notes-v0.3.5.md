# v0.3.5 — 基本设置改为「改完立即生效」

## 🐞 抖动输入后切页又被还原成 10

- **现象**:在「基本设置」的随机抖动里填任意 ≤30 的数字,**不点保存**直接切页,回来又变回 10。
- **根因**:这一页所有输入都只在按「保存设置」时才写盘,而每次进入页面都会用存档值回填 ——
  没保存的输入被静默丢弃。要求用户记得点保存,本身就是设计问题。
- **修复**:整页改成改完立即生效:
  - 抖动 / PIN:输入后 700ms 自动保存(防抖,避免每敲一位就重排一次闹钟);
  - 六个开关(自动检查更新 / 锁屏处理 / 完成后回锁 / 常驻保活 / 静默亮度 / Root 解锁)勾选即生效;
  - 离开页面、输入框失焦、退出应用时都会立即落盘;
  - 输入超过 30 会把夹取后的**实际生效值回显**,不再"显示 35、实际 30";
  - 输入框为空(正在重新输入)时保留原值,不写默认值。

> 「保存设置」按钮保留,作为"立即保存并重排定时"的手动入口。
