# v0.3.2 — 修复「给了自启动权限仍显示未完成」

## 🐞 问题

在系统里允许了自启动,回到应用引导页却仍显示「未完成 / 去设置」。

## 根因

**系统不提供「自启动是否已允许」的查询接口** —— 任何 App 都读不到这个状态,只能由用户确认。
上一版把这个确认做成了列表下方一个不显眼的按钮,从设置页回来时很容易漏点,
表现出来就是「明明给了权限还是未完成」。

## 修复

- 从系统设置页**回到引导页时自动弹确认框**:「已经在系统里允许了吗?」
  → [已允许,标记完成] / [再打开一次] / [还没设置];
- 确认按钮文案改成「我已在系统里允许自启动 → 标记完成」;
- 同样的处理也用于**关闭电池优化**:部分 ROM 的「省电策略:无限制」并不等于系统电池优化白名单,
  同样查不到状态,现在也能手动确认;
- 顶部进度从「已完成 6 / 7 项」改为**显式列出还差哪几项**。
