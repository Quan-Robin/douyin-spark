# v0.3.4 — 抖动设置、Root 检测、更新说明排版

## 🐞 随机抖动「改不动」其实是三个输入框互相覆盖

- **现象**:在「基本设置」把抖动从 10 改成 20,保存后过一阵又变回 10。
- **根因**:无障碍页 / 协议页各自也有一个抖动输入框,且只在**首次进入时**回填一次
  (为保护"未保存的输入"而加的 `inputsSynced` 守卫)。你在基本设置改完抖动后,
  模式页手里还是旧值,再点一次「保存」就把旧值写回去了 —— 保存链路有三条,谁后点谁说了算。
- **修复**:抖动**只保留在「基本设置」**一处;两个模式页改为只读提示
  「随机抖动:±20 分钟 · 在「基本设置」里修改」;模式页保存时不再写抖动,沿用已存值;
  保存基本设置后让模式页下次进入重新回填。

## 🐞 Root 检测「点了没提示」

- **根因**:检测代码**没有超时、也不排空 stderr** —— Magisk 弹授权框时 `su` 会一直挂着,
  `waitFor()` 永久阻塞,后台线程再也回不来,用户什么提示都收不到。
- **修复**:先立刻显示「正在检测…(若弹出授权框请点允许)」;执行带 15 秒超时,超时即 `destroy` 进程;
  结论分四种:找不到 su / 无法执行 su / 超时未响应 / 已授权或授权被拒;
  并写入**常驻状态行**,不再只是一闪而过的 Toast。

## 🎨 更新说明的 Markdown 排版

- **现象**:更新弹窗直接显示 Release 说明原文,满屏 `#`、`**`、表格竖线。
- **修复**:新增极简 Markdown 渲染器(`MarkdownLite`):标题去符号并加粗、列表转 •、
  表格转 `a · b`、行内加粗 / 等宽 / 链接只保留可读文字;内容放进可滚动区域,长说明也能读完。
