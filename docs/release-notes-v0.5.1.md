# v0.5.1 — 界面风格打磨(对齐 / 间距 / 圆角 / 字距)

> 纯样式改动:**没有动任何功能逻辑**(发送、定时、权限、解锁、更新检测全部未改)。

## 🎨 这次打磨了什么

- **底部导航**:图标与文字严格对齐(去掉字体内边距 `setIncludeFontPadding(false)`,消除基线偏移),
  图标 22dp、文字 10sp 单行,触控条目 58dp;
- **顶栏**:‹ 返回与 ⋮ 菜单改成 **48dp 圆角涟漪按钮**,标题左内边距对齐;
- **卡片**:圆角统一 18dp、内边距 16dp,**去掉描边改用微投影**(深色模式下不带阴影,避免发灰);
- **小节标题**:改小到 12.5sp 并加 0.04 字距(M3 分组标题风格),颜色降一档;
- **内容留白**:左右 16dp 统一在内容容器上,各页不再各自 padding(以前会叠加);
- **首页状态区**:每行之间加细分隔线(`Ui.hairline`),数值**单行省略**,长文案不再挤压错位;
- **徽章**:全圆角药丸;输入框圆角 14dp、最小高度 48dp;按钮更大更饱满,主按钮加 0.02 字距;
- **配色微调**:浅色页面底色 0xFFF6F7F9、分割线 0xFFE8EAEF;深色 0xFF0E1116 / 0xFF191E26 / 0xFF232A33 / 0xFF2A323C。
