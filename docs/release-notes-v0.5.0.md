# v0.5.0 — 界面全面重做(底部导航 + 深色模式)

> 纯前端改动:发送、定时、权限、解锁等后端逻辑**零改动**。

## 🎨 这次改了什么

- **底部导航栏**替代左侧图标竖栏(首页 / 无障碍 / 协议 / 设置 / 关于,图标 + 文字标签):
  拇指可达、内容区更宽,选中项主色高亮 + 涟漪反馈;
- **深色模式**:设置 → 外观,可选「跟随系统 / 浅色 / 深色」,点了**立即生效**(切换后自动回到设置页);
  页面 / 卡片 / 输入框 / 文字 / 涟漪 / 状态栏与导航栏配色整体切换,时间滚轮文字也做了适配;
- **系统栏与主题**:新增 `styles.xml`(`NoActionBar`,修掉部分机型"系统标题栏 + 自绘顶栏"的双标题栏),
  状态栏 / 导航栏颜色跟随界面;
- **首页状态区结构化**:原来一大段纯文本,改成「发送模式 / 下次运行 / 今日发送」标签 + 数值行,
  运行中多一行当前状态;今日已发送显示绿色;
- **触控与细节**:按钮最小高度 48dp;复选框统一主色、点击区更大;
  时间编辑器 ＋/✕ 改为圆形涟漪按钮(删除键红色、只剩一行时置灰);
  关于页改用应用图标;「更新源」过期文案修正;网页登录页加顶栏、版本号改为动态读取;
- **引导页**:切换发送方式不再整页重建(不再丢滚动位置),两张卡片原地刷新;
- **构建修复**:`build.sh` 的 javac/d8 未带 `libs/` 里的 Shizuku 库(单独跑该脚本会编不过),已补齐。

## 已知小瑕疵(不影响使用)

- 深色模式下,系统的 AlertDialog(如"发现新版本")仍是浅色 —— 因为 `AppTheme` 的父主题是 Light;
  彻底修需要再定义一个深色主题并在 `applyTheme` 里 `setTheme()`,留到下一版;
- `AccessibilityConfigActivity` 已无任何入口(仅清单里留着),本次未删。
