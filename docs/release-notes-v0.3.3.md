# v0.3.3 — 接上真实的更新检测

## 🔄 更新检测

之前只是个占位接口(没配更新源,点了提示「更新服务暂未配置」)。现在接上真实的 Release 接口:

| | |
|---|---|
| 数据源 | 先 **Gitee**(国内快),失败自动切 **GitHub**(`releases/latest`) |
| 判断 | 比较 Release 的 tag 与当前版本号 |
| 有新版本 | 弹窗:**去下载** / **忽略此版本** / **以后再说** |
| 去下载 | 直接取 Release 附件 `SparkKeeper.apk`;取不到则退回发布页 |
| 忽略 | 记在本地,自动检查不再为这个版本反复打扰(手动检查仍会提示) |
| 自动检查 | **每天一次**,可在「基本设置」里关闭 |
| 手动检查 | 「关于」页按钮 / 右上角菜单 |
| 失败处理 | 明确报错、不影响使用,结果写入运行日志 |

> App **不会**静默自安装 —— 那需要「安装未知应用」权限,风险比收益大。点「去下载」用浏览器下载后手动安装即可。

## 怎么验证更新检测

1. 装 v0.3.2 的 APK(上一个 Release),打开 App;
2. 「关于 → 检查更新」应立即提示发现 **v0.3.3**;
3. 点「去下载」应能直接下载到 v0.3.3 的 APK。
