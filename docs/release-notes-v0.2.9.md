# v0.2.9 — 首个公开版本

抖音自动续火花:每天在设定时间附近自动给指定好友发一条消息,维持火花不断。仓库含**两个互相独立的实现**。

## 📱 手机端:`SparkKeeper.apk`(Android 原生,不需要电脑)

| | |
|---|---|
| 版本 | v0.2.9(versionCode 11) |
| 体积 | 95.5 KB |
| 支持 | Android 7.0+ |
| SHA256 | `831337330A4091EB57628E9979482AA2A66B8F16F1D25669D8BEFE64478EA530` |

**两种发送模式**
- **无障碍模式**(稳定):用无障碍服务操作手机上已登录的抖音 App,自动进会话、输入、发送。
- **协议模式**(实验性,已真机跑通):内嵌 WebView 打开抖音网页版,在后台自动发送 —— **不亮屏、不需要电脑**。

**功能**:每日多个发送时间点 · 随机抖动 0–30 分钟(可关) · 消息池随机 · 每日防重发 · 失败重试 ·
锁屏处理(滑动锁自动解锁、密码锁等你解锁后补跑) · Root PIN 解锁(实验性) · 静默亮度 · 常驻保活 ·
界面结构 dump(抖音改版后便于适配)。

**安装**:安装后打开 App → ① 开启无障碍服务 → ② 填好友名 → ③ 填消息池 → ④ 设时间与抖动 → ⑤ 保存定时。
**首次请勾选「测试模式」跑一遍**(走完整流程但不真发)。系统设置里给「续火花」和抖音**关闭电池优化/允许自启动**。

## 本次版本修了什么(相对最初可用版本)

**协议模式(此前实际跑不起来)**
- 运行标志 `PROTO_RUNNING` 用完不复位 → 一个进程只能成功运行一次;
- `ABORT` 在协议链路无人复位 → 点过一次「停止运行」后永久失效;
- 选择器单点硬编码、页面内长定时器等待(SPA 一跳转就丢回调)、两个搜索框的坑、wujie shadow root;
- 离屏 WebView 窗口带 `FLAG_NOT_FOCUSABLE` → 页面拿不到焦点,受控编辑器(Slate)拿不到插入点,文字进不了编辑器内部状态;
- 横屏/分屏时离屏位移按"应用窗口宽度"算 → 屏幕上会露出网页画面,现按真实屏幕计算并跟随旋转;
- 发送判定错用"编辑器是否清空"(该版本发送成功后编辑器仍有残渣)→ 误判失败并重复发送,现改为发送前后指纹对比。

**无障碍模式**
- 「防发错人」校验形同虚设(两条分支都返回 true);
- Root 解锁失败、用户自己解锁后,运行结束会把手机当面重新锁上;
- Root 命令只读一行就 `waitFor`,输出超管道缓冲会永久阻塞;
- 时间配置写入 `sendTime` 而调度只读 `times` → 模式页改时间被静默忽略;
- 覆盖安装后系统丢弃闹钟、`setExactAndAllowWhileIdle` 无权限时崩溃、`nextTime` 用 `+86400000` 加天数;
- 「常驻保活」勾选不生效、配置页先写盘再校验、切页丢未保存输入、静默亮度缺少 `WRITE_SETTINGS` 声明。

**电脑端**
- 守护模式发送时间被推向窗口末端(每轮重摇抖动)、`--only` 名字写错反报成功、`state.json` 结构异常崩溃、
  `send_time` 不带引号被 YAML 解析成六十进制整数导致永不发送、`send -v` 报参数错误、日志目录不一致。

## ⚠️ 使用须知

- 本工具只是**替你完成"打开会话 → 输入 → 发送"这几个点击**,不修改抖音客户端、不逆向通信协议,也不收集/上报任何数据。
- 请遵守抖音用户协议,**仅用于个人账号的日常互动**;不要配置大量好友或高频发送,以免触发风控。账号风险自担。
- 电脑端的 `user_data/` 是完整浏览器 profile(含登录 Cookie),**等同于账号凭据**,请勿提交或分享。
- 抖音改版后选择器可能失效,`docs/douyin-web-chat-selectors.md` 是校准用的对照表。
